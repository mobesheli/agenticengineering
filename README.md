# Agentic Engineering

This repository holds runnable companion code for *Agentic AI Engineering*.

Current contents:

- `chapter 2/`: a simple Python-first OpenAI Agents SDK training project based on a financial services claims pipeline.
- `chapter 3/`: a guided notebook for tool design, function calling, side-effect safety, MCP wiring, and a financial services audit-prep agent.
- `chapter 4/`: a guided notebook for agent memory, retrieval, sessions, forgetting, and a medication reconciliation agent.
- `chapter 5/`: a guided notebook for orchestration patterns, request routing, model routing, human approval routes, and a financial crime alert triage pyramid.
- `chapter 6/`: a guided notebook and tested A2A project for signed Agent Cards, task lifecycles, defensive remote-agent calls, and a cross-company supply-chain sourcing run.

# Agentic Engineering

This repository holds runnable companion code for *Agentic AI Engineering*.

Current contents:

- `chapter 2/`: a tested claims pipeline on the OpenAI Agents SDK: typed outputs, async tools with timeouts, attached guardrails, deterministic escalation rules, tracing, and a runnable example for every chapter section.
- `chapter 3/`: a guided notebook for tool design, function calling, side-effect safety, MCP wiring, and a financial services audit-prep agent.
- `chapter 4/`: a guided notebook for agent memory, retrieval, sessions, forgetting, and a medication reconciliation agent.
- `chapter 5/`: a guided notebook for orchestration patterns, request routing, model routing, human approval routes, and a financial crime alert triage pyramid.
- `chapter 6/`: a guided notebook and tested A2A project for signed Agent Cards, task lifecycles, defensive remote-agent calls, and a cross-company supply-chain sourcing run.
- `chapter 7/`: a guided notebook and tested evaluation harness for golden tasks, trajectory grading, calibrated judges, abuse cases, statistical regression gates, and model-risk evidence packs.
- `chapter 8/`: a guided notebook and tested code for securing a medication reconciliation agent: a tool catalog enforced by a guardrail, a split session, approvals bound to one exact action, a write policy with a budget, redaction before trace export, a decision log with a signed checkpoint, and an emergency stop drill.
- `chapter 9/`: a guided notebook and tested code for measuring what a maintenance planning agent costs and returns: a price card, a meter around every model call, a run budget with a repeated-call guard, a ledger that joins identity, cost, and outcome, a border span for calls to another organization, a model for each step, and cost per approved order against a baseline.
- `chapter 10/`: a guided notebook and tested deployment companion for a worker that pauses and resumes at an approval, tool contracts, release bundles, a release pipeline with an evaluation gate, kill switches, agent intake, evidence-based listing, and a four-route dashboard.
- `chapter 11/`: a guided notebook and tested code for running an agent through its first year: reading the configuration the provider reports, a drift check with five decisions, an autonomy ladder with a ceiling, a spending mandate, a scored memory hygiene pass with lineage and erasure, fleet reconciliation and contract checks, a gate for fixes the agent proposes, and a retirement script.

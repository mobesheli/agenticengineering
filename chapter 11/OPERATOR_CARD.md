# The Operator's Card

Use these questions at an operating review. Record the evidence location and the person responsible for each unanswered question.

| Subsystem | Questions |
| --- | --- |
| Reasoning | Which model and settings are serving now, and do they match the bundle? Which signal would reveal an upstream improvement or regression? Which evaluated route takes over if the primary disappears? |
| Tools | What could this identity do before anyone reads an alert? What are the current rung, ceiling, promotion evidence, and automatic drop triggers? What proves reviewers are still reading? |
| Memory | Can every fact be traced to its source event? When did hygiene last pass both recall and forgetting probes? Can an erasure request reach summaries, embeddings, archives, and backups? |
| Orchestration | Which consumers would break if this contract changed? Who receives the infrastructure page and the behavior page, and can they stop the agent? What authority does an outside agent actually have? |
| Constraints | Can the proposer change its grader, logs, or stop controls? Who owns the criteria, and when were the graders challenged? When were both damage and paging clocks last measured? |

For every agent: **whose name is on it, and did they sign this quarter?**
